# Security

## Reporting a problem

Please report a vulnerability privately, through GitHub's
[private reporting](https://github.com/xenolphthalein/overpressure/security/advisories/new) for this repository, not
in a public issue.

## What is in scope

The installed system's network exposure and logins, and anything in the tooling or the images that could harm a
headset or its owner's data. What the system protects and what it doesn't is in
[devices/phoenix/docs/security.md](devices/phoenix/docs/security.md). Its bootloader is unlocked by design: someone
holding the headset can reach its data.

Only the latest release gets fixes.
