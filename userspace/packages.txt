# Frame's private base has, and its Turnip lacks KGSL anyway.

libxxf86vm
mesa
xorg-xwayland
pipewire
pipewire-pulse
wireplumber

pico4/pico4-turnip-kgsl
pico4/pico4-graphics-tests

# Project-built: host daemons for the sensor DSP (head IMU, XR.md); python runs
# the pico4-imu client
pico4/pico4-sensors
python

# Project-built: Monado OpenXR runtime with the PICO 4 head-tracking driver, and
# Basalt as its SLAM backend for 6DoF (XR.md)
pico4/pico4-monado
pico4/pico4-basalt
# Arch's OpenCV links its highgui module against Qt without depending on it;
# Monado and Basalt load that module
qt6-base

# Valve's VR session as on the Steam Frame (SESSION.md): SteamVR for
# linuxarm64 and the session scripts and user units around gamescope's OpenVR
# backend. pacman.conf leaves out SteamVR's Frame-only drivers and tools. The
# "steamvr" script needs jq.
deckard-arch-hotfixes-release-0.3/deckard-steamvr-session
deckard-arch-hotfixes-release-0.3/deckard-steamvr-rel
# Project-built: the panels as SteamVR's direct-mode display (Vulkan layer)
pico4/pico4-vrdisplay
# Project-built: System V semaphores, which SteamVR needs and the kernel lacks
pico4/pico4-sysvsem
jq
# SteamVR's dashboard (vrwebhelper, CEF) links ATK and AT-SPI; gamescope-onready
# runs xhost and xrdb before it reports the session ready
at-spi2-core
xorg-xhost
xorg-xrdb
# "!name" satisfies dependencies on name without installing it. The Steam

!deckard-steam
!sddm
